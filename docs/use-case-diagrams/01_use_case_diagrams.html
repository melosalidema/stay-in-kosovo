Use Case Diagrams

UML-style use case diagrams for Stay in Kosovo: web, mobile/PWA, API backend, roles, and third-party services.

Back to index Open full Markdown overview

Legend

Mermaid does not provide a native use-case diagram type, so these diagrams use flowchart notation to approximate UML: actors are rectangular external nodes, use cases are rounded nodes, subgraphs are system boundaries, solid arrows show actor/API usage, and dotted arrows show include/extend relationships.

ActorRoleMain use cases
Tourist / Local UserPrimary visitor using the product for exploration.Discover places, recommendations, city pulse, mobility, itinerary, reviews, assistant, weather.
Web UserDesktop/tablet browser user.Opens the same Next.js app and consumes the API through browser fetch calls.
Mobile UserPhone/PWA user.Uses the mobile-first responsive app, install/offline support, same shared API endpoints.
Business OwnerAuthenticated role for operator features.Business dashboard, onboarding, upload signature, visibility and analytics.
AdminAuthenticated administrator.Moderation queues, platform metrics, business/review/location oversight.
External ServicesProviders outside the app.Weather, map images, uploads, OAuth, future AI narrative/chat enhancement.

Backend stepResponsibilityCode mapping
